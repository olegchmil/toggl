# Учёт рабочего времени

Простой self-hosted трекер рабочего времени в стиле [Toggl](https://toggl.com): без базы данных,
без регистрации, без внешних зависимостей — достаточно обычного PHP-хостинга.

Таймер на одну кнопку, ручное редактирование записей, экспорт отчётов в CSV (совместимый
с форматом Toggl) по «ссылке для руководителя» без входа в систему.

## Возможности

- Запуск/остановка таймера одной кнопкой, один активный таймер на пользователя.
- Ручной ввод времени начала и корректировка любых записей (в том числе в прошедших месяцах).
- Автоматическая проверка пересечений интервалов: при совпадении времени обе записи
  подсвечиваются, сохранение блокируется с сообщением «Пересекается время конца и начала».
- Несколько пользователей (до 50), общий список проектов, роли «админ» / «пользователь».
- Админ управляет проектами и пользователями прямо в интерфейсе.
- Экспорт месяца в CSV в формате Toggl и прямая «ссылка для руководителя» по секретному ключу.
- Длительности и итог за месяц в формате `ЧЧ:ММ:СС` (часы:минуты:секунды).
- Лёгкая страница без внешних библиотек и CDN, работает и без JavaScript (формы), умещается
  на одном файле интерфейса.

## Требования

- PHP 7.4+ (рекомендуется 8.x) с расширениями `mbstring`, `session`, `json`, `fileinfo`
  (первые три обязательны, в стандартной сборке включены).
- Право на запись в папку `data/` (обычный PHP-хостинг или Apache/Nginx + PHP-FPM).

## Быстрое развёртывание

1. Скопируйте все файлы проекта на сервер (например, в `public_html/toggl`).
   ```
   .htaccess          (не обязателен; см. «Структура»)
   config.php
   config.local.php.example
   lib.php
   api.php
   index.php
   export.php
   data/
   ```
2. Убедитесь, что папка `data/` доступна для записи веб-серверу:
   ```
   chmod 775 data
   ```
   (или `777`, если сайт под другим владельцем).
3. Откройте `index.php` в браузере. При первом запуске появится форма создания
   администратора — задайте логин, пароль и имя.
4. Готово. Войдите и нажмите «▶ Старт».

> При создании пользователей и записи таймера файлы создаются автоматически.
> Отдельные операции «настройки базы» не нужны.

## Конфигурация

Все параметры задаются в `config.php` или в локальном файле `config.local.php`
(не публикуется в git — создаётся на каждом сервере).

| Параметр            | Где               | Назначение                                              |
|---------------------|-------------------|---------------------------------------------------------|
| `EXPORT_KEY`        | `config.local.php` | Секретный ключ для «ссылки для руководителя»            |
| `APP_TITLE`         | `config.php`      | Заголовок страницы                                      |
| `APP_BASE_URL`      | `config.php`      | Базовый URL, если нужно жёстко задать (обычно `''`)     |
| часовой пояс        | `config.php`      | `date_default_timezone_set(...)`, по умолчанию Владивосток |

### Секретный ключ экспорта

Скопируйте `config.local.php.example` → `config.local.php` и вставьте свой ключ:

```
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
```

Либо задайте переменную окружения `TOGGL_EXPORT_KEY` (удобно на Docker/PaaS).
Без настроенного ключа «ссылка для руководителя» работать не будет.

### Расположение в подпапке

Если проект лежит в подкаталоге (`https://site.ru/toggl/`), ничего настраивать не нужно:
`APP_BASE_URL = ''` — относительные пути и подкаталог определяются автоматически.

## Использование

- **Старт/стоп** — кнопка «▶ Старт»; время старта фиксируется в момент нажатия.
  Если заранее ввести время в поле «Время начала», оно будет использовано.
- **Редактирование** — «Изменить» в строке записи: карточка появляется сразу над списком,
  время, проект и описание можно править в любом месяце.
- **Пересечения** — при попытке сохранить запись, пересекающуюся по времени с другой,
  обе строки подсвечиваются красным, сохранение блокируется.
- **Месяц** — переключатель месяцев, список записей и итог за месяц.
- **Админ** — вкладка «Управление»: добавление пользователей, список проектов.

## Экспорт CSV и «ссылка для руководителя»

Кнопка **«Скачать CSV»** скачивает отчёт за текущий месяц. Колонки совпадают с Toggl,
а `Start time`, `End time` и `Duration` выводятся в формате `ЧЧ:ММ:СС`; длительность
считается с учётом перехода через полночь:

```
"User","Email","Client","Project","Task","Description","Billable",
"Start date","Start time","End date","End time","Duration","Tags"
```

В карточке месяца есть кнопка **«Ссылка для руководителя»** — она выдаёт URL вида
`export.php?key=...&login=...&period=YYYY-MM`. Открыв его, руководитель без входа
скачает CSV-отчёт. Доступ только по секретному ключу (см. `EXPORT_KEY`).

## Безопасность

- Пароли хранятся как хеши `password_hash()` (bcrypt).
- Сессия `HttpOnly` + `SameSite=Lax`; вход только по паролю, капча не требуется.
- Файлы в `data/` защищены от прямого доступа файлом `.htaccess` (Apache). Для Nginx
  закройте каталог на уровне конфигурации (`location /toggl/data { deny all; }`).
- Обязательно смените `EXPORT_KEY` на свой — он попадает в публичные ссылки.
- Используйте HTTPS на сервере.

## Структура проекта

```
config.php              — базовые настройки и часовой пояс
config.local.php        — локальные секреты (в git не публикуется)
lib.php                 — работа с JSON-хранилищем, сессиями, helpers
api.php                 — JSON-API (start/stop/update/delete/list/projects/users)
index.php               — интерфейс (вход, таймер, список, правки, админ)
export.php              — выгрузка CSV по ключу или сессии
data/                   — хранилище: users.json, projects.json, <login>_<ГГГГ-ММ>.json
```

## Как хранятся данные

Никакой базы данных — один JSON-файл на пользователя на месяц:

```
data/
  users.json                  — список пользователей
  projects.json               — общий список проектов
  oleg_2026-08.json           — записи пользователя oleg за август 2026
```

Записи хранятся с временем в локальном часовом поясе сервера. Резервная копия = копия
папки `data/`.

## Локальная разработка

```
php -S 127.0.0.1:8080 -t .
```

Откройте http://127.0.0.1:8080/ и создайте администратора.
